Chromium switches for when a video stays black or pages draw wrong. Each one takes effect at the next launch; turn one on at a time, relaunch, and check the page again. Help → Copy Diagnostics reports which are active.

Split view can tile its panes any way you like. A layout is rows separated by |, columns by /, weights as numbers; a row may start with its own weight and a colon. 50/50 | 100 puts two panes on top and one across the bottom; 2:50/50 | 1:100 makes the top row twice as tall. Up to four panes. Drag the gaps between panes to adjust a layout live.

Chrome extensions

Chord loads unpacked extensions: a folder with a manifest.json. Download the extension’s source or unzip its .crx, then pick that folder. Content scripts, storage and most page-level APIs work; toolbar popups are not shown.

A boost is CSS and JavaScript of yours that runs on the sites you name. Sites: comma separated, example.com covers its subdomains, *.example.com only subdomains, * everything. CSS applies live; JavaScript runs at page load, so a change needs a reload.

The AI mode of a space talks to the model you configure here. It can list and read the space’s tabs, open and navigate them, fetch URLs, and call tools that pages expose through WebMCP. Nothing is sent anywhere until you write in the panel.

Local models need no key: run Ollama (ollama run llama3.1) and keep the default base URL. For Anthropic the model defaults to claude-opus-5-5; requests opt into Anthropic’s server-side fallback so a safety decline is retried on another Claude model. Pages can offer tools to the assistant with navigator.modelContext.registerTool(...) (WebMCP); Chord provides that API when Chromium does not.
