Chromium switches for when a video stays black or pages draw wrong. Each one takes effect at the next launch; turn one on at a time, relaunch, and check the page again. Help → Copy Diagnostics reports which are active.

Google rejects sign-ins from browsers it takes for embedded apps (“This browser or app may not be secure”). On its sign-in pages only, Chord can identify as Firefox or as Electron, which Google treats differently; every other site sees plain Chromium. If one choice fails, reload the sign-in page with the other.


Split view can tile its panes any way you like. A layout is rows separated by |, columns by /, weights as numbers; a row may start with its own weight and a colon. 50/50 | 100 puts two panes on top and one across the bottom; 2:50/50 | 1:100 makes the top row twice as tall. Up to four panes. Drag the gaps between panes to adjust a layout live.

MCP server

Local MCP serverLets Claude Desktop and other MCP clients on this computer list spaces and tabs, read pages, open and navigate tabs, search history and call the tools pages expose. Bound to 127.0.0.1 and protected by a token.

Paste the copied JSON into Claude Desktop → Settings → Developer → Edit Config (claude_desktop_config.json), merging the chord entry into mcpServers, and restart Claude Desktop. It uses npx mcp-remote, so Node.js must be installed. Clients that speak Streamable HTTP directly can use the URL below with the token as a bearer header.

Chord loads unpacked extensions: a folder with a manifest.json. Download the extension’s source or unzip its .crx, then pick that folder. Content scripts, storage and most page-level APIs work; toolbar popups are not shown.

Local models need no key: run Ollama (ollama run llama3.1) and keep the default base URL. For Anthropic the model defaults to claude-opus-5-5; requests opt into Anthropic’s server-side fallback so a safety decline is retried on another Claude model. Pages can offer tools to the assistant with navigator.modelContext.registerTool(...) (WebMCP); Chord provides that API when Chromium does not.

      

      

        
Chord keeps your spaces and bookmarks in two GitHub repositories it creates for you: a private one (chord-sync: spaces, favorites, appearance, every bookmark) and a public one (chord-bookmarks: your public bookmarks as a page on GitHub Pages, with an RSS feed others can follow in a curated space). Private, password-locked spaces never leave this computer. Changes are pushed about half a minute after you make them and pulled at launch and every 15 minutes; pulls only add, never remove.

        

          

            
            

              
              
A GitHub personal access token with the repo scope (classic) or, fine-grained, with Administration, Contents and Pages write access on all repositories, so Chord can create the two repositories and write to them. Create one on GitHub. It is stored encrypted with your operating system's keychain.
