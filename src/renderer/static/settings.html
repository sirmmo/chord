A boost is CSS and JavaScript of yours that runs on the sites you name. Sites: comma separated, example.com covers its subdomains, *.example.com only subdomains, * everything. CSS applies live; JavaScript runs at page load, so a change needs a reload.

        

          Make a page Chord-integrated: the API boosts can use
          
On a site you wrote a boost for, navigator.chord is unlocked without a prompt. It runs in the page, so it can read anything the page shows and turn it into Chord's own things:

          
    
            
  • chord.card.set({ title, subtitle, state, badge, actions }) — a card in the sidebar, shown from every space; state is ok, warn, err or busy (busy also shows a chip in the title bar); up to four actions: [{ id, label }] become buttons, answered with chord.card.onAction(id => …); chord.card.clear() removes it.
    • 
            
  • chord.setUnread(n) — the badge on the tab and the space dot (null goes back to reading the title). chord.notify(title, body) — counted like a web notification.
    • 
            
  • chord.bookmark({ url, title, note, tags, public }), chord.addNote(markdown) (appended to the space's notes), chord.subscribe(feedUrl?) (the reader, tagged with the space), chord.open(url, { background }), chord.openLittle(url).
    • 
            
  • chord.openTab/closeTab/focusTab/navigateTab/listTabs/setSubspaceName — the page's own subspace of tabs (see the page API docs).
    • 
            
  • await chord.theme() → { space: { id, name, color, icon }, accent, dark, font }; the same arrives as CSS variables --chord-space, --chord-accent and data-chord-theme="dark|light" on <html> for your CSS, and as a theme event when it changes.
    • 
            
  • Players: set navigator.mediaSession.metadata and action handlers and the page gets a now-playing card. Tools for the AI mode and the MCP server: navigator.modelContext.registerTool(…).
    • 
          

          
Example — a site's inbox count on the tab and a card with one button:


const chord = navigator.chord;
const count = () => document.querySelectorAll('.inbox .unread').length;
const update = () => { chord.setUnread(count()); chord.card.set({ title: 'Inbox', subtitle: `${count()} unread`, state: count() ? 'warn' : 'ok', actions: [{ id: 'compose', label: 'Compose' }] }); };
chord.card.onAction(id => { if (id === 'compose') document.querySelector('.compose-button').click(); });
new MutationObserver(update).observe(document.body, { childList: true, subtree: true });
update();

Sync as a KeePass file

        
With GitHub sync on, your passwords can travel in the private repository as passwords.kdbx, a KeePass file (KDBX 4, Argon2) encrypted with a master password of its own. Other computers running Chord with the same master password merge it; KeePassXC and friends open it too. Nothing leaves this computer until a master password is set.

Chord keeps your spaces and bookmarks in two GitHub repositories it creates for you: a private one (chord-private: spaces, favorites, appearance, every bookmark) and a public one (chord-bookmarks: your public bookmarks as a page on GitHub Pages, with an RSS feed others can follow in a curated space). Private, password-locked spaces never leave this computer. Changes are pushed about half a minute after you make them and pulled at launch and every 15 minutes; pulls only add, never remove.

A connected space is kept together by several people: everyone with its join link gets the space, and whatever anyone pins, removes, renames or writes in its notes reaches the others within seconds. Chord talks to an MQTT broker over TLS only, and the space itself travels sealed with a key that lives in the join link, so the broker never sees it. Today tabs, live folders and what is open on screen stay personal.

        

          
          

            
            
All connected spaces you create go through this broker; the join link carries it, so people you invite reach the same one. HiveMQ's public broker by default: anyone can use it, which is fine because the content is sealed. Only mqtts:// and wss:// are accepted.
