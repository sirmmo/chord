Everything Chord does, and why you will want it

Chord is the browser for people who got used to Arc and are not going back to a tab strip. This page walks through what you get, group by group, then hands over to the shortcuts, the install notes and the developer reference.

Browse the way Arc taught you

The sidebar, Spaces and the command bar are the heart of it. They work the way your hands already know, with the same shortcuts.

⌘⇧N · Ctrl+1…9

Spaces keep your lives apart

Work, home, a client, a hobby: each Space has its own colour, icon, pinned and today tabs. Jump between them from the keyboard or the dots at the bottom of the sidebar, and the whole window tints so you always know where you are.

⌘S

A sidebar instead of a tab strip

Vertical tabs with the page's navigation controls and a URL pill. Collapse it to give the page the whole window, hover the left edge to peek at it, drag its edge to resize.

⌘D

Favorites and pinned tabs that behave

Favorites sit in a grid shared by all Spaces and reflow with the sidebar width. Pinned tabs stay put: closing one puts it to sleep and resets it to the page you pinned, closing it again removes it.

Folders

Folders and subspaces

Group related tabs under a collapsible header. Make an empty folder and drop tabs into it, or start a subspace from a tab. Folders stay when empty, pages can fill a subspace of their own, and Chord fills live folders for you.

12 hours

Today tabs that tidy themselves

Tabs you stop using are archived after the delay you choose. The archive stays searchable from the command bar, so a closed tab is never lost.

⌘T · ⌘L

One command bar for everything

URLs, searches, open tabs, bookmarks, history, archived tabs and every command, in one box. Prefixes narrow it down; hold ⌘ on Enter to force a new tab.

⌘⇧D

Split view your way

Up to four pages side by side. Built-in layouts, or your own in a short spec such as 50/50 | 100 for two on top and one across the bottom. Drag the gaps to adjust.

Peek

Peek before you commit

A link that leaves the site of a pinned or favorite tab opens in a preview over the page. Esc closes it, ⌘⇧O makes it a tab.

Little

Little windows for links from other apps

A link from Slack or Mail opens in a small window of its own instead of hijacking your Space. One button moves it into a Space when it deserves to stay.

⌘N

Several windows, one Space each

Open a Space in its own window, drag tabs between windows, and find every window back where you left it at the next launch.

Routes

Air Traffic Control

Links from the sites you name land in the Space you choose, wherever they come from. Jira in the work Space, YouTube in the fun one, without thinking about it.

⌘⇧L

An address bar, if you want one

Off by default. One shortcut shows an editable URL field across the top of the page for the days you miss it.

Make it yours

Arc had Boosts and Easels. Chord has them, plus the knobs Arc never exposed.

CSS · JS

Boosts

Your own CSS and JavaScript per site, applied live. A boost can also put cards, badges and notifications in the sidebar through the page API, turning any site into a Chord-aware one.

Easel

An easel per Space

Sticky notes, links, clipped text, pictures and page snapshots on a canvas you pan and zoom. Paste or drop anything, right-click a page to add a selection. Export as Markdown.

Markdown

Notes and bookmarks per Space

Every Space has a notes page with a split Markdown editor. Bookmarks take tags and notes, per Space and across all of them, private or published on your own page.

⌘,

Your colours, your icons, your font

Light, dark or system. Any colour per Space, tint strength, a separate accent, colour or monochrome icons, favicons or letters, and four typefaces.

Skins

LCARS

One switch turns the chrome into an LCARS homage: black panels, peach and lavender pills, condensed uppercase type. Pages stay as they are.

Keep loaded

Tabs that are always on

Mark a tab to keep it loaded: it wakes at launch, loads in the background in Spaces you are not looking at, and is never archived. Mail and chat stay current.

Settings

Settings you can find

Seventeen short pages in five groups, from Tabs & windows to Troubleshooting. Each ends with an Advanced fold for the rare knobs, so the common ones stay in view.

JSON

Export, import, hand-edit

Your whole setup, or a single Space, is one readable JSON file. Move it to another computer, share a Space with a colleague, or write one by hand.

Arc · Chrome · Brave · Firefox

Bring everything along

Arc Spaces with folders, pinned and today tabs and favorites; bookmarks from Chrome, Brave, Edge, Chromium and Firefox; the history of any of them. Merge into what you have or replace it.

Private by default

Arc had an ad blocker. Chord has a privacy stack, on from the first launch, with a switch for each part.

DNS · GPC · HTTPS

Privacy that is already on

Encrypted DNS through Quad9, Global Privacy Control on every request, no third-party cookies, HTTPS first with a fallback, and a fresh e-mail alias from SimpleLogin or Firefox Relay on any form. All under Settings → Privacy.

Shields

Ads and trackers blocked

EasyList and EasyPrivacy built in, on by default, with one switch per site. Chrome Web Store extensions install from a pasted address or the puzzle button on a store page.

🔒

Private Spaces

Give a Space a password. It locks on launch, when you leave it and after fifteen minutes away. Its tabs are never exported, archived, synced or written to history.

Profiles

Separate logins per Space

Give a Space its own profile and its cookies and logins stay apart from the rest. Two Google accounts, two Spaces, no more signing out.

Passkeys · Passwords

A password manager with passkeys

Saved with the OS keychain, protected by Touch ID or Windows Hello, filled when you want. Passkeys are created and used in Chord, security keys keep working. Sync them as a KeePass file you can open anywhere.

⌘Y

History that stays home

Every page you visit, by day, searchable, with per-entry removal. Stored on your computer and nowhere else.

Work together, stay in sync

No Chord account, no Chord servers. Your data travels through repositories you own, or straight between the people you invite.

GitHub

Sync through your own GitHub

Sign in and Chord creates two repositories for you: a private one that keeps your Spaces, bookmarks and passwords on every computer, and a public one GitHub Pages serves as your linkroll, with an RSS feed others can follow.

MQTT

Connected Spaces, live

Send a join link and the Space is kept together by everyone who holds it: whatever anyone pins, removes, renames or writes in the notes reaches the others within seconds. Sealed end to end, through a TLS broker you choose.

Share

Share a Space or a page

Publish a Space on your GitHub Pages as an installable link. Anyone with Chord opens it as a Space of their own, everyone else sees the tabs. A single page shares the same way, with a note.

Add to Chord

Installable Spaces from any site

A site can publish a Space manifest: one click sets up a Space with all its pages and optional boosts. Declare it with a link tag or an "Add to Chord" link.

Curated

Follow the finders

A curated Space follows people who share: blogs and newsletters, Bluesky and Mastodon accounts, a GitHub user's stars, a repository's releases, subreddits, channels. Their finds arrive in the side panel and open in the Space.

RSS

A reader, built in

Subscriptions in subspaces, unread marks, a reading pane, keyboard navigation. A feed button appears on every site that offers one, an OPML file becomes a subspace, and you can export yours any time.

Live

Live folders

Subspaces that fill themselves: pull requests waiting for your review, issues assigned to you, GitHub notifications or any search, a feed's latest items, bookmarks with a tag. Tabs come and go with the source.

A browser that pays attention

Chord reads what your pages are doing and puts the controls where you are, in every Space.

♪ · ☎ · ⏱

Smart pages

Players get a now-playing card with play, pause, previous, next and volume. Calls on Meet, Zoom or Jitsi get a card with duration, mute, camera and leave. Timers, unread counts and notifications show as chips and badges.

GitHub · VS Code

Developer pages

A pull request shows its state, checks and branch, spins while checks run, notifies when they finish, and re-runs from the sidebar. VS Code in the browser shows the file, branch, errors, tasks and debug sessions.

Tray

Music and calls go on when the window closes

Optionally the window hides instead of closing. The menu bar or tray item offers play, pause, mute, a volume submenu per player, leave and downloads.

Share

Screen sharing that works

Sharing uses the system picker on macOS 15 and Chord's own screen, window and tab picker elsewhere.

PiP

Picture in picture that follows you

Pop a video out by hand, or let a playing video pop out on its own when you switch away from its tab.

Widevine

Music and video that play

Built on castLabs' Electron with the Widevine CDM, so Amazon Music, Spotify, Netflix and Prime Video work as in Chrome. The CDM downloads on first launch.

⌘⇧J

Downloads in view

A progress ring in the title bar, the current file above your Spaces, and a downloads page with pause, resume, cancel, retry and open.

Updates

Keeps itself current

Chord checks for new releases after launch and every few hours. The Windows installer and the AppImage update themselves on restart; the other builds get a one-click download.

Research, AI and automation, per Space

Modes turn a Space into a workbench. Each one is a switch on the Space, not a setting for the whole browser.

Research

Research mode

A side panel for notes, clips and sources, with one-click saving to Zotero.

Sources

Sources mode, with Sourceror

Checks any article against the reliability lists Wikipedia editors keep, Crossref and OpenAlex: who is behind each link, dead links, retractions and claims that rest on nothing, marked in the page. Needs the free Sourceror server on your computer.

AI

AI mode, your model

A side-panel assistant on a local or remote model, with your own key. It reads and drives the tabs of that Space and calls the tools pages expose through WebMCP. Nothing is sent until you write.

MCP

Drive it from Claude Desktop

A local MCP server, off by default, lets an assistant on your computer read your tabs, open pages and use the tools sites expose. One click copies the Claude Desktop config.

Install in a minute

Pick the build for your system from the latest release. It updates itself afterwards.

Downloads

  • macOS 13 or later: one universal .dmg that runs natively on Apple Silicon and Intel. If an older per-architecture build warns about Rosetta, replace it with this one.
  • macOS 12 Monterey: -mac-universal-legacy.dmg, the same app on Electron 43, the last Electron that runs on Monterey. It gets every Chord release but fewer Chromium security updates, so move to the main build when you can.
  • Windows: -setup.exe installer, or -portable.zip to unpack anywhere; it keeps its data in ChordData next to Chord.exe (x64).
  • Linux: .AppImage and .deb (x64).
Builds are not signed or notarised yet. On macOS, if the app refuses to open, run xattr -cr /Applications/Chord.app once. On Windows, choose "More info → Run anyway" in SmartScreen.

Staying up to date

Chord looks for new releases a short while after launch and every few hours (Settings → Updates, or Help → Check for Updates…). The Windows installer and the Linux AppImage download the new version and install it when Chord restarts. The macOS build is not notarised and cannot replace itself, so Chord offers the new dmg and you drag it over the old copy; the portable zip and the deb work the same way.

Requires Node 22 or newer.

For developers and site owners

Three ways to plug into Chord: an installable Space, a page that manages its own tabs, and the MCP server.

Installable spaces

Publish a chord-space manifest over https and declare it with <link rel="chord-space" href="…"> or an <a href="chord://install/?url=…">Add to Chord</a> link. Chord shows what it contains and asks before installing. Boosts in a manifest may only target the publishing domain. Add "dynamic": true to grant the page API below on install.

Dynamic pages

Inside Chord, https pages get navigator.chord. A page may open and close tabs of its own, grouped under it as a subspace, and is told when the user closes one. It never sees the user's other tabs. The first call asks once per origin; Settings → Tabs & windows → Advanced lists and revokes grants. Closing the page closes its subspace. Type declarations.

{
  "format": "chord-space", "version": 1,
  "name": "Stairway", "icon": "🪜", "dynamic": true,
  "pinned": [{ "url": "https://stairway.example/", "title": "Experiments" }]
}

// on the page
if ('chord' in navigator && await navigator.chord.requestTabs()) {
  await navigator.chord.setSubspaceName('Experiments');
  const tab = await navigator.chord.openTab({
    url: 'https://stairway.example/exp/42', activate: false });
  navigator.chord.addEventListener('tabclosed',
    (e) => console.log('closed', e.detail.id));
  await navigator.chord.closeTab(tab.id);
}

MCP server

Let Claude Desktop, or any MCP client on your computer, work in your browser.

Settings → MCP server starts a Streamable HTTP endpoint on 127.0.0.1:23120/mcp, protected by a token Chord keeps in its profile folder. One button copies a ready Claude Desktop configuration; paste it into claude_desktop_config.json and restart Claude Desktop.

Tools: list spaces and tabs, read a page's text, open, navigate, focus and close tabs, fetch a URL, search history, list downloads, and whatever the focused page exposes through WebMCP. Locked private spaces stay closed. Off by default, loopback only.

{
  "mcpServers": {
    "chord": {
      "command": "npx",
      "args": ["-y", "mcp-remote",
        "http://127.0.0.1:23120/mcp",
        "--header", "Authorization: Bearer <token>"]
    }
  }
}

Configuration files

File → Export Configuration… writes your setup to JSON; Import Configuration… reads one back, merging or replacing. Right-click a Space to export just that one.

Merge adds what is missing: Spaces with the same name receive the tabs they do not have yet, other Spaces are created, favorites are added, settings are left alone.

Replace rebuilds Spaces, favorites and settings from the file. Your current tabs are moved to the archive, so nothing is lost.

The format has no internal ids and is meant to be written by hand too. A tab is a URL string or an object with url, title, favicon and an optional group (its subspace). A Space may list folders by name and liveFolders with their source. Imported tabs stay asleep until you open them.

{
  "format": "chord-config",
  "version": 1,
  "favorites": ["https://mail.example.com"],
  "spaces": [
    {
      "name": "Work",
      "color": "#ff6b6b",
      "icon": "💼",
      "folders": ["Reading"],
      "pinned": [{ "url": "https://github.com/sirmmo/chord", "title": "Chord", "group": "Reading" }],
      "today": ["https://news.ycombinator.com"]
    }
  ],
  "settings": {
    "searchEngine": "duckduckgo",
    "archiveAfterHours": 24,
    "theme": { "mode": "dark", "accent": "#ffb347", "iconStyle": "mono" }
  }
}

How it works

A small Electron app with one strict rule: all state changes go through a pure reducer, and the native views are reconciled from the state.

Every click, shortcut or page event becomes an action. reduce(state, action) in src/shared/model.ts returns the next state and knows nothing about Electron, so it is covered by plain node:test unit tests.

The main process then reconciles: it creates a WebContentsView for every tab that should be awake, destroys the rest, lays out the visible panes (one or a split), persists the session and broadcasts the state to the sidebar page. UI, views and the saved session stay consistent by construction.

The sidebar is the window's own page. Because native views always paint above it, the command bar and the find bar live in a separate transparent view layered on top.

src/shared/   types, reducer, URL and layout helpers (no Electron)
src/main/     Electron main process
  controller  state, actions, commands, broadcasting
  tabs        one WebContentsView per awake tab, reconciled
  overlay     transparent view: command bar and find bar
  menu        app menu and context menus
  session     partition, UA, permission prompts, Shields
src/preload/  contextBridge API (window.chord)
src/renderer/ sidebar page and overlay page
test/         node:test suite for the model

Pick something from the roadmap or fix what annoys you. Most fixes ship within days.

Working on it

  1. Fork and clone, then npm install.
  2. npm run watch rebuilds on save; run npx electron . in another terminal.
  3. Keep logic in the reducer and add a test in test/model.test.ts.
  4. npm run typecheck && npm test must pass; CI runs them and packages every platform.
  5. Open a pull request. Tagging vX.Y.Z publishes a GitHub release with installers for all three platforms.
