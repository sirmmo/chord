The browser you missed, open source.

Chord is a browser inspired by Arc: a sidebar instead of a tab strip, Spaces to keep contexts apart, a command bar instead of a URL bar, split view, and ad blocking built in. MIT licensed, built on Electron.

Download Source on GitHub

macOS (one universal build), Windows (installer or portable) and Linux (AppImage, deb). Early and moving fast; builds are unsigned, and Chord tells you when a new release is out.

What it does

The parts of Arc that change how you browse, without the parts that phone home.

Profiles

Separate logins per space

Give a space its own profile and its cookies and logins stay apart from the rest; give several spaces the same profile and they share it. Two Google accounts, two spaces.

Modes

Research and AI, per space

Turn on Research for notes, clips, sources and one-click saving to Zotero, Sources to audit an article’s references with Sourceror, or AI for a side-panel assistant on a local or remote model that reads and drives the tabs of that space and calls the tools pages expose through WebMCP.

Sources

Sourceror, built in

A Sources mode checks any article against the reliability lists Wikipedia editors keep, Crossref and OpenAlex: who is behind each link, dead links, retractions, claims that rest on nothing, and candidate sources for them, marked right in the page. Needs the free Sourceror server on your computer.

MCP

Drive it from Claude Desktop

A local MCP server, off by default, lets an assistant on your computer read your tabs, open pages and use the tools sites expose. One click copies the Claude Desktop config.

⌘N

Several windows

Each window shows one space; open a space in its own window from its context menu, drag tabs between spaces and therefore windows, and find every window back where you left it at the next launch.

Updates

Keeps itself current

Chord checks for new releases after launch and every few hours. The Windows installer and the AppImage update themselves on restart; the macOS build, the portable zip and the deb get a one-click download instead.

Share

Screen sharing and calls

Meet, Zoom and Jitsi get mute, camera and leave controls in the sidebar. Sharing uses the system picker on macOS 15 and Chord's own screen, window and tab picker elsewhere.

Subspaces

Groups inside a space

Collapse related tabs under a header, drop tabs onto it, rename or dissolve it. Pages can manage a subspace of their own through navigator.chord: a dashboard keeps one tab per job and tidies up after itself.

Add to Chord

Installable spaces

A site can publish a space manifest: one click sets up a space with all its pages, and optional boosts for that site. Declare it with a link tag or an “Add to Chord” link.

CSS · JS

Boosts

Your own CSS and JavaScript per site, applied live. Passwords saved with the OS keychain, picture in picture that follows you between tabs.

🔒

Private spaces

Give a space a password: it locks on launch and when you leave it, and its tabs are never exported, archived, or written to history.

♪ · ☎ · ⏱

Smart pages

Players get a now-playing card with play, pause, previous and next. Screen sharing works with the system picker on macOS 15+ and Chord's own screen/window/tab picker elsewhere. Calls on Meet, Zoom or Jitsi get a card with duration, mute, camera and leave. Timers, unread counts and notifications show as chips and badges. All of it from every space.

GitHub · VS Code

Developer pages

A pull request, issue or workflow run gets a card with its state, the checks tally and the branch, a spinning chip while checks run, a notification when they finish, and re-run from the sidebar. VS Code in the browser (vscode.dev, Codespaces, code-server) shows the file, unsaved mark, branch, errors and warnings, tasks and debug sessions, from every space.

Skins

LCARS

One switch in Appearance turns the chrome into an LCARS homage: black panels, peach and lavender pills, condensed uppercase type. Pages stay as they are.

Tray

Keep playing when closed

Optionally the window hides instead of closing: music and calls go on, and the menu bar / tray item offers play, pause, mute, a volume submenu per player, leave and downloads. Per-tab volume lives on the player card and the tab's speaker icon too.

Little

Little windows

Links from other apps open in a small window of their own, with one button to move the page into a space. Hover the left edge to peek at a collapsed sidebar.

RSS

A reader, built in

Subscriptions in subspaces, unread marks, a reading pane, keyboard navigation. A feed button appears in the sidebar on every site that offers one; an OPML file becomes a subspace; export yours any time.

Easel

A canvas per space

Sticky notes, links, clipped text, pictures and page snapshots on a freeform canvas you pan and zoom. Paste or drop anything; right-click any page to add a selection or an image. Export as Markdown.

Markdown

Notes per space

Every space has a notes page in Markdown with a split editor and preview; bookmarks take Markdown notes too, per space and across all spaces.

GitHub

Bookmarks that sync and publish

Private or public bookmarks with tags and notes. Paste a GitHub token and Chord creates two repositories for you: a private one that keeps your spaces and bookmarks on every computer, and a public one that GitHub Pages serves as your linkroll, with an RSS feed others can follow.

Curated

Follow the finders

A curated space follows people who share: blogs and newsletters, Bluesky and Mastodon accounts, a GitHub user’s stars, a repo’s releases, subreddits, channels. Their finds arrive in the side panel with unread marks and filters, and open in the space.

Widevine

Music and video that play

Built on castLabs’ Electron with the Widevine CDM, so Amazon Music, Spotify, Netflix and Prime Video work like in Chrome. The CDM downloads on first launch.

Passkeys

Passkeys, built in

Create and use passkeys on any site: Chord asks you (Touch ID where available) and answers the site itself. Keys are encrypted with the OS keychain and stay on your computer; security keys keep working, and Windows Hello is one setting away.

Keep loaded

Tabs that are always on

Mark a tab to keep it loaded: it wakes at launch, loads in the background in spaces you are not looking at, and is never archived. Off by default, one click in the tab menu.

⌘S

Collapsible sidebar

Vertical tabs with the page's navigation controls, a URL pill and the lists below. Collapse it to go full page and hover the left edge to peek; drag its edge to resize.

⌘⇧L

Address bar, if you want one

An optional editable URL field across the top of the page. Off by default, one shortcut away.

Add-ins

Shields and extensions

Built-in ad and tracker blocking, plus Chrome extensions installed straight from the Web Store (paste the address, or press the puzzle button on a store page) or unpacked from a folder, each switchable in Settings. Toolbar popups are not shown.

⌘,

Your colours, your icons

Light, dark or system theme. Any colour per Space, tint strength, a separate accent, colour or monochrome icons with their own colour, and your choice of font.

⌘⇧N · Ctrl+1…9

Spaces

Every Space has its own colour, icon, pinned and today tabs. Switch with the keyboard or the dots at the bottom of the sidebar.

⌘D

Favorites and pinned tabs

Favorites sit in a grid shared by all Spaces. Pinned tabs never close: closing one puts it to sleep and resets it to the page it was pinned at.

12 hours

Today tabs that clean up

Ephemeral tabs are archived after a period of inactivity you choose. The archive stays searchable from the command bar.

⌘T · ⌘L

Command bar

One box for URLs, search, open tabs, archived tabs and commands. Hold ⌘ on Enter to force a new tab.

⌘⇧D · ⌘⌥L

Split view, your way

Tile up to four panes with built-in layouts or your own, such as 50/50 | 100 for two on top and one below, and drag the gaps between panes to adjust. Up to four pages side by side. Add from the keyboard, a tab's context menu, or a link's context menu.

⌘Y

History

Every page you visit, by day, searchable, with per-entry removal. Stored locally, never sent anywhere.

⌘⇧J

Downloads

A progress ring in the title bar, the current file above your spaces, and a downloads page with pause, resume, cancel, retry and open.

Arc · Chrome · Brave

Bring your tabs along

Import Arc spaces, pinned and today tabs and favorites, or the bookmarks of Chrome, Brave, Edge and Chromium, as spaces of pinned tabs. Merge into what you have or replace it.

JSON

Export and import

Save all your Spaces, tabs, favorites and settings to a JSON file, or a single Space. Import it elsewhere, merging into what is there or replacing it.

Chromium

Renders like Chrome

Pages behave exactly as in Chrome, Brave or Arc. Per-site permission prompts, OAuth popups opened as tabs, find in page, sleep and mute.

Install

Grab an installer from the latest release, or build from source.

Downloads

  • macOS 13 or later: one universal .dmg that runs natively on Apple Silicon and Intel. If an older per-architecture build warns about Rosetta, replace it with this one.
  • macOS 12 Monterey: -mac-universal-legacy.dmg, the same app on Electron 43, the last Electron that runs on Monterey. It gets every Chord release but fewer Chromium security updates, so move to the main build when you can.
  • Windows: -setup.exe installer, or -portable.zip to unpack anywhere; it keeps its data in ChordData next to Chord.exe (x64).
  • Linux: .AppImage and .deb (x64).
Builds are not signed or notarised yet. On macOS, if the app refuses to open, run xattr -cr /Applications/Chord.app once. On Windows, choose “More info → Run anyway” in SmartScreen.

Staying up to date

Chord looks for new releases a short while after launch and every few hours (Settings → General → Updates, or Help → Check for Updates…). The Windows installer and the Linux AppImage download the new version and install it when Chord restarts. The macOS build is not notarised and cannot replace itself, so Chord offers the new dmg and you drag it over the old copy; the portable zip and the deb work the same way.

From source

Requires Node 22 or newer.

git clone https://github.com/sirmmo/chord.git
cd chord
npm install
npm start          # build and launch
npm test           # model unit tests
npm run dist:mac   # .dmg in release/

For site owners

Two ways a site can meet Chord halfway: an installable space, and a page that manages tabs of its own.

Installable spaces

Publish a chord-space manifest over https and declare it with <link rel="chord-space" href="…"> or an <a href="chord://install/?url=…">Add to Chord</a> link. Chord shows what it contains and asks before installing. Boosts in a manifest may only target the publishing domain. Add "dynamic": true to grant the page API below on install.

Dynamic pages

Inside Chord, https pages get navigator.chord. A page may open and close tabs of its own, grouped under it as a subspace, and is told when the user closes one. It never sees the user's other tabs. The first call asks once per origin; Settings → General lists and revokes grants. Closing the page closes its subspace. Type declarations.

{
  "format": "chord-space", "version": 1,
  "name": "Stairway", "icon": "🪜", "dynamic": true,
  "pinned": [{ "url": "https://stairway.example/", "title": "Experiments" }]
}

// on the page
if ('chord' in navigator && await navigator.chord.requestTabs()) {
  await navigator.chord.setSubspaceName('Experiments');
  const tab = await navigator.chord.openTab({
    url: 'https://stairway.example/exp/42', activate: false });
  navigator.chord.addEventListener('tabclosed',
    (e) => console.log('closed', e.detail.id));
  await navigator.chord.closeTab(tab.id);
}

MCP server

Let Claude Desktop, or any MCP client on your computer, work in your browser.

Settings → Add-ins → Local MCP server starts a Streamable HTTP endpoint on 127.0.0.1:23120/mcp, protected by a token Chord keeps in its profile folder. One button copies a ready Claude Desktop configuration; paste it into claude_desktop_config.json and restart Claude Desktop.

Tools: list spaces and tabs, read a page's text, open, navigate, focus and close tabs, fetch a URL, search history, list downloads, and whatever the focused page exposes through WebMCP. Locked private spaces stay closed. Off by default, loopback only.

{
  "mcpServers": {
    "chord": {
      "command": "npx",
      "args": ["-y", "mcp-remote",
        "http://127.0.0.1:23120/mcp",
        "--header", "Authorization: Bearer <token>"]
    }
  }
}

Configuration files

File → Export Configuration… writes your setup to JSON; Import Configuration… reads one back, merging or replacing. Right-click a Space to export just that one.

Merge adds what is missing: Spaces with the same name receive the tabs they do not have yet, other Spaces are created, favorites are added, settings are left alone.

Replace rebuilds Spaces, favorites and settings from the file. Your current tabs are moved to the archive, so nothing is lost.

The format has no internal ids and is meant to be written by hand too. A tab is a URL string or an object with url, title, favicon and an optional group (its subspace). Imported tabs stay asleep until you open them.

{
  "format": "chord-config",
  "version": 1,
  "favorites": ["https://mail.example.com"],
  "spaces": [
    {
      "name": "Work",
      "color": "#ff6b6b",
      "icon": "💼",
      "pinned": [{ "url": "https://github.com/sirmmo/chord", "title": "Chord" }],
      "today": ["https://news.ycombinator.com"]
    }
  ],
  "settings": {
    "searchEngine": "duckduckgo",
    "archiveAfterHours": 24,
    "theme": { "mode": "dark", "accent": "#ffb347", "iconStyle": "mono" }
  }
}

How it works

A small Electron app with one strict rule: all state changes go through a pure reducer, and the native views are reconciled from the state.

Every click, shortcut or page event becomes an action. reduce(state, action) in src/shared/model.ts returns the next state and has no idea Electron exists, so it is covered by plain node:test unit tests.

The main process then reconciles: it creates a WebContentsView for every tab that should be awake, destroys the rest, lays out the visible panes (one or a split), persists the session and broadcasts the state to the sidebar page. UI, views and the saved session stay consistent by construction.

The sidebar is the window's own page. Because native views always paint above it, the command bar and the find bar live in a separate transparent view layered on top.

src/shared/   types, reducer, URL and layout helpers (no Electron)
src/main/     Electron main process
  controller  state, actions, commands, broadcasting
  tabs        one WebContentsView per awake tab, reconciled
  overlay     transparent view: command bar and find bar
  menu        app menu and context menus
  session     partition, UA, permission prompts, Shields
src/preload/  contextBridge API (window.chord)
src/renderer/ sidebar page and overlay page
test/         node:test suite for the model

Contribute

Chord is young and most of the work is still ahead. Pick something from the roadmap or fix what annoys you.

Roadmap

  • Air Traffic Control: route links from chosen sites into a chosen space
  • History import from Chrome, Brave, Edge and Arc; a Firefox importer
  • Signed and notarised macOS and Windows builds

Working on it

  1. Fork and clone, then npm install.
  2. npm run watch rebuilds on save; run npx electron . in another terminal.
  3. Keep logic in the reducer and add a test in test/model.test.ts.
  4. npm run typecheck && npm test must pass; CI runs them and packages every platform.
  5. Open a pull request. Tagging vX.Y.Z publishes a GitHub release with installers for all three platforms.
